# VyanHQ Draw v1.14

Compact, resizable OBS dock with:
- Draw button for private host canvas (no member room required)
- outline profile button to copy member link
- Connect button to create a member room with a name
- Forget button to clear the locally stored member room
- OBS-native hotkeys for Clear Member Drawings, Lock, Unlock, Toggle Canvas
- automatic OBS Browser Source creation/update
- private host drawing via /hostdraw
- Cloudflare Worker + Durable Object backend

## Build
Use the same Windows GitHub Actions workflow that previously produced a clean OBS 32.2.2 x64 build.
